Grass 字幕助手

YouTube の動画ページで開いてください。

先に、動画の説明の「文字起こしを表示」を押して、右の「動画の関連情報」で「文字起こし」タブを開いてください（字幕のない動画では使えません）。

時間が空欄なら、最初から／最後まで。両方空欄で全部の字幕を読みます。

Drive に保存するための設定

Grass アプリの「設定」と同じ Apps Script の URL とトークンを入れてください。保存先は マイドライブ / pwa / transcript です（なければ作ります）。

読むのは、押したときに画面に見えている文字起こしだけです。範囲を入れたときは、その外は保存しません。「Drive に保存」は マイドライブ / pwa / transcript に置きます。スマホの Grass の「生の日本語 → 学習パックを読み込む」で開きます。
