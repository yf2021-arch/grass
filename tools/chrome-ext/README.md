# Grass 字幕助手（Chrome 拡張・PC 用・試作 0.4.1）

YouTube の動画ページで、自分で開いた「文字起こし」パネルから、選んだ30〜90秒の字幕だけを
学習パック（`grass-rawpack` v1）にして保存します。スマホの Grass「生の日本語 → 学習パックを読み込む」で開きます。

- 権限は `activeTab`・`scripting`・`storage`。ポップアップを開いたときに、今のタブだけを読みます（cookie・履歴・音声には触れません）
- 「Drive に保存」（0.4.0）：Grass の Apps Script に送り、マイドライブ / pwa / transcript に JSON を置きます（`gas/Transcripts.gs`）。
  送り先は自分の Apps Script だけ（`script.google.com`）。URL とトークンはこの PC の拡張の中（chrome.storage.local）にだけ保存します
- 読むのは画面に見えている文字起こしだけ。パネルがない・字幕がない動画では「ない」と表示し、補ったりしません
- 自動字幕は「未確認」として保存します。字幕の全文は公開しません（パックは自分のスマホだけで使います）
- YouTube の画面の作りが変わると、読めなくなることがあります
  - 0.3.0：時間を空欄にすると、全部（または最初から／最後まで）を読む。終わりが空欄のときは動画の長さまで
  - 0.2.0：2026-11 の新しいパネル（「動画の関連情報」→「文字起こし」・`transcript-segment-view-model`）に対応。前のパネルも読めます
  - 新しいパネルには字幕の言語・自動字幕かどうかが出ないので、パックの字幕の種類は「分からない（未確認）」になります

## 更新したとき
`chrome://extensions` の「Grass 字幕助手」で ↻（再読み込み）を押す

## 入れ方（使うときだけ）
1. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオン
2. 「パッケージ化されていない拡張機能を読み込む」で、このフォルダ（tools/chrome-ext）を選ぶ

## 使い方
1. YouTube の動画を開き、動画の説明の「文字起こしを表示」を押す → 右の「動画の関連情報」で「文字起こし」タブ
2. 拡張のアイコンを押す → 「今の時間」で始まりと終わり（空欄なら最初から／最後まで。両方空欄で全部）→ 「字幕を読む」
3. 中身を確かめて「Drive に保存」（または「ファイルに保存」）→ スマホの Grass で読み込む

## Drive に保存の準備（最初の1回）
1. Apps Script（登録スクリプト）に `gas/Transcripts.gs` を新しいファイルとして貼り付ける
2. 本体の `doPost` に1行足す（ほかの action と同じ場所）：`if (action === 'transcript') return saveTranscriptApi_(payload);`
3. 「デプロイ > デプロイを管理 > 編集 > 新バージョン」で公開し直す（URL は変わらない）。Drive を使う許可を求められたら許可する
4. 拡張の「Drive に保存するための設定」に、Grass アプリの設定と同じ URL とトークンを入れて「保存」
   - 拡張のファイルを入れ替えたら、`chrome://extensions` で ↻（再読み込み）する。しないと新しい権限（storage）が効かない
   - 0.4.1：storage 権限がなくても、拡張の中（localStorage）に保存するので、次に開いても残る
   - または、このフォルダに `config.json` を置いてもよい：`{ "apiUrl": "https://script.google.com/macros/s/…/exec", "token": "…" }`
     （トークンが入るので、人に渡したり公開リポジトリに入れたりしない。`.gitignore` に入れてある）
