# Grass 字幕助手（Chrome 拡張・PC 用・試作 0.1）

YouTube の動画ページで、自分で開いた「文字起こし」パネルから、選んだ30〜90秒の字幕だけを
学習パック（`grass-rawpack` v1）にして保存します。スマホの Grass「生の日本語 → 学習パックを読み込む」で開きます。

- 権限は `activeTab` と `scripting` だけ。ポップアップを開いたときに、今のタブだけを読みます（cookie・履歴・音声には触れません）
- 読むのは画面に見えている文字起こしだけ。パネルがない・字幕がない動画では「ない」と表示し、補ったりしません
- 自動字幕は「未確認」として保存します。字幕の全文は公開しません（パックは自分のスマホだけで使います）
- YouTube の画面の作りが変わると、読めなくなることがあります

## 入れ方（使うときだけ）
1. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオン
2. 「パッケージ化されていない拡張機能を読み込む」で、このフォルダ（tools/chrome-ext）を選ぶ

## 使い方
1. YouTube の動画を開き、動画の下の「…」→「文字起こしを表示」
2. 練習したい場面で拡張のアイコンを押す → 「今の時間」で始まりと終わり → 「字幕を読む」
3. 中身を確かめて「学習パックを保存」→ ファイルを Drive などでスマホへ → Grass で読み込む
