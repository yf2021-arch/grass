# Grass — 日本語知識バンクの復習アプリ（PWA）

Grass_日本語知識バンク_MASTER の `01_知識カード` を、Android のスマホで毎日復習するためのアプリです。
オフラインでも使え、電波が戻ると評価をシートに送ります。

## しくみ

```
Claude（grass-card-extractor）──register──▶ Apps Script ◀──pull / progress── このアプリ
                                              │
                                      01_知識カード（正本）
```

- **pull**：全カードと 03_設定 の復習間隔を取得し、スマホの中（IndexedDB）に保存します
- **progress**：評価の結果を書き戻します。書くのは「状態・次回復習日・復習段階・最終結果」の4列だけです
- 評価はまずスマホに保存され、送信待ちに積まれます。同期できたら消えます

## 1. Apps Script を更新する（URL は変わりません）

1. スプレッドシートの「拡張機能 > Apps Script」を開き、`Grass_Inbox_Import.gs` の中身に置き換えて保存
2. 「デプロイ > デプロイを管理」→ 鉛筆アイコン →「バージョン：新バージョン」→「デプロイ」

新しいデプロイは作らないでください（URL が変わってしまいます）。setup をもう一度実行する必要はありません。

## 2. GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例：`grass`）。無料プランの Pages は **Public** リポジトリが必要です。
   このフォルダには URL もトークンも入っていないので、公開しても大丈夫です
2. 「Add file > Upload files」で、このフォルダの中身（`index.html` がいちばん上に来るように）をアップロード
3. 「Settings > Pages」で Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存
4. 1〜2分後、`https://<ユーザー名>.github.io/grass/` で開けます

## 3. Android にインストールする

1. Chrome で上の URL を開く
2. メニュー（︙）→「アプリをインストール」または「ホーム画面に追加」

## 4. シートとつなぐ

1. アプリの「設定 > 接続」を開く
2. スプレッドシートの `10_API設定` シートから **URL** と **TOKEN** をコピーして貼る
3. 「保存して接続」→「つながりました（○枚）」と出れば完了

接続前に「デモデータで試す」で流れを確認できます（デモ中はシートに何も送りません）。

## 復習のルール（03_設定 と同じ）

| ボタン | 次回 | 復習段階 | 最終結果 |
|---|---|---|---|
| できた | 次の間隔（1→3→7→14→30→60日）。60日の次は「定着」 | +1 | 正解 |
| あいまい | 3日後 | そのまま | 部分正解 |
| 忘れた | 明日 | 0 に戻る | 不正解 |

- 復習の右上のかばんアイコン（職場で使えた）を押してから評価すると、状態が「使える」になります
- 受信箱からは毎日「1日の新規カード」の枚数まで、優先度順・古い順で自動的に学習に入ります
- 間隔を変えたいときは 03_設定 の「復習間隔」を書き換えて同期します

## イメージ図と語の家族（v1.1.0）

- 復習の表では、ヒント1が **イメージ図**（絵）になります。絵のないカードは、これまでどおり根源イメージの文です
- 裏の「語源・根源・イメージ図」に同じ絵が出ます。同じ家族のカードがあれば「語の家族」から一覧で見比べられます
- 絵は 「イメージ図」列（AC列）の JSON から、アプリが描きます（型は motion／body／kanji／timeline／contrast／scale）
- 既存の139枚の絵は `data/visuals.json` に入っていて（描き直した絵は `rev: 2`。シートの絵より版が新しければアプリはこちらを使う）、イメージ図列が空でもアプリに表示されます
- シートにも入れたいときは、`gas/ImportVisuals.gs` を Apps Script に追加して `grassImportVisuals` を一度実行します
  （見出し「イメージ図」がなければ右端の次の列＝今は AC列に作り、空のセルにだけ書きます）。新しいカードは、Claude のスキルが最初からこの列に入れます。列は見出し名で探すので、位置が変わっても動きます
- 絵を直すときは `tools/build_visuals.py` を編集して `python3 tools/build_visuals.py` を実行します。
  `tools/gallery.html` で全部の絵を一覧できます

## 話す練習（v1.3.0）

下のナビの「話す」から使います。シートにも Apps Script にも変更はありません。記録と詰まりメモは、このスマホの中（IndexedDB の meta）にだけ保存されます。

- **場面から言う**：場面の説明を見て、日本語で声に出して言う →「答えを見る」→ 型・説明・1か所だけ変えた言い換え3つを確かめる →「言えた／詰まった」
  - 答えを見るまでの秒数を自動で記録します（「話す」画面に今週の回数と平均を表示）
- **読んで、顔を上げて言う**（Read and Look Up）：文を読んで覚える →「顔を上げる」で文が隠れる → だれかに話すつもりで言う。
  「ちらっと見る」は1.5秒だけ文を出し、見た回数を記録します
- 出す順：まだ練習していないもの → 前回「詰まった」もの → 前回からいちばん時間がたったもの。機能（報告・確認・相談・依頼・お詫び・動作・状態・会議）で絞り込めます
- **詰まりメモ**：言えなかったことを一行だけ記録（中国語・英語でも可）。分かった言い方を後から足せます。
  「まとめてコピー」で `REGISTER:` の文になるので、Claude に貼って送ると grass-card-extractor がカードにします。送ったら「送った分を片付ける」
- 素材は `data/chunks.json` の30個。場面はすべて架空・一般的なもので、会社の情報は入れないでください

### 音声（AivisSpeech）

答えと言い換えの 🔊 は、`data/audio/` の音声ファイルを再生します。ファイルがない文は端末の読み上げを使い、それもなければ案内を出します。

1. PC で AivisSpeech を起動する
2. `python tools/make_audio.py --list` で声の番号を調べる
3. `python tools/make_audio.py --speaker 番号`（聞き取り練習なら `--speed 0.9` も）
4. できた `data/audio/`（音声＋`manifest.json`）をリポジトリに入れて公開する

- ファイル名に「文＋声＋速さ」の記号が付くので、文を直して作り直すと、その文だけが新しくなります（古いファイルは削除）
- スマホでは、一度再生した音声を `grass-audio` キャッシュに保存し、次からは通信しません。アプリを更新しても消えません。
  「話す」画面の「音声をまとめてダウンロード」で、Wi-Fi のときに全部入れておくこともできます
- **声のモデルのライセンス（ACML／ACML-NC／CC0 など）を確認してください。** リポジトリは公開なので、音声の公開が認められているモデルを使います。
  クレジットは `manifest.json` の `credit` に入り、「話す」画面に表示されます

## アプリを更新するとき

ファイルを直したら、`sw.js` の `VERSION`（例：`grass-v1.1.0`）を上げてからアップロードしてください。
スマホ側は、次に開いたときに裏で新しい版を取得し、その次に開いたときから新しい版になります。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 入口 |
| `css/app.css` | デザイン（キャンバス「Grass Japanese PWA」の色・文字・寸法。ダークモード対応） |
| `js/app.js` | 10の画面と操作（語の家族・話すを含む） |
| `js/srs.js` | 復習のルール、今日のセッションの組み立て |
| `js/sync.js` | シートとの同期 |
| `js/store.js` | スマホ内の保存（IndexedDB） |
| `js/demo.js` | デモ用カード |
| `js/visual.js` | イメージ図を描く（型ごとのテンプレート） |
| `js/speak.js` | 話す練習（場面から言う・読んで顔を上げる・詰まりメモ・音声） |
| `data/chunks.json` | 話す練習の素材（職場の決まった言い方30個） |
| `data/audio/` | 話す練習の音声（`tools/make_audio.py` で作る） |
| `data/visuals.json` | 既存カードのイメージ図と語の家族 |
| `gas/ImportVisuals.gs` | 既存カードの「イメージ図」列（AC列）を埋める Apps Script |
| `tools/` | イメージ図のデータ作成と一覧、`make_audio.py`（AivisSpeech で音声を作る） |
| `sw.js` | オフライン対応（Service Worker） |
| `manifest.webmanifest`, `icons/` | インストール用 |

## 安全について

トークンは設定画面で入れたスマホの中にだけ保存されます。スマホをなくしたときは、
スプレッドシートのメニュー「Grass > トークンを再発行」で古いトークンを無効にしてください
（そのあと、Claude のスキルは 10_API設定 から新しいトークンを自動で読みます）。
