# Grass — 日本語知識バンクの復習アプリ（PWA）

Grass_日本語知識バンク_MASTER の `01_知識カード` を、Android のスマホで毎日復習するためのアプリです。
オフラインでも使え、電波が戻ると評価をシートに送ります。

## しくみ

```
Claude（grass-card-extractor）──register──▶ Apps Script ◀──pull / progress── このアプリ
                                              │
                                      01_知識カード（正本）
```

- **pull**：全カードと 03_設定 の復習間隔を取得し、スマホの中（IndexedDB）に保存します
- **progress**：評価の結果を書き戻します。書くのは「状態・次回復習日・復習段階・最終結果」の4列だけです
- 評価はまずスマホに保存され、送信待ちに積まれます。同期できたら消えます

## 1. Apps Script を更新する（URL は変わりません）

1. スプレッドシートの「拡張機能 > Apps Script」を開き、`Grass_Inbox_Import.gs` の中身に置き換えて保存
2. 「デプロイ > デプロイを管理」→ 鉛筆アイコン →「バージョン：新バージョン」→「デプロイ」

新しいデプロイは作らないでください（URL が変わってしまいます）。setup をもう一度実行する必要はありません。

## 2. GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例：`grass`）。無料プランの Pages は **Public** リポジトリが必要です。
   このフォルダには URL もトークンも入っていないので、公開しても大丈夫です
2. 「Add file > Upload files」で、このフォルダの中身（`index.html` がいちばん上に来るように）をアップロード
3. 「Settings > Pages」で Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存
4. 1〜2分後、`https://<ユーザー名>.github.io/grass/` で開けます

## 3. Android にインストールする

1. Chrome で上の URL を開く
2. メニュー（︙）→「アプリをインストール」または「ホーム画面に追加」

## 4. シートとつなぐ

1. アプリの「設定 > 接続」を開く
2. スプレッドシートの `10_API設定` シートから **URL** と **TOKEN** をコピーして貼る
3. 「保存して接続」→「つながりました（○枚）」と出れば完了

接続前に「デモデータで試す」で流れを確認できます（デモ中はシートに何も送りません）。

## 復習のルール（03_設定 と同じ）

| ボタン | 次回 | 復習段階 | 最終結果 |
|---|---|---|---|
| できた | 次の間隔（1→3→7→14→30→60日）。60日の次は「定着」 | +1 | 正解 |
| あいまい | 3日後 | そのまま | 部分正解 |
| 忘れた | 明日 | 0 に戻る | 不正解 |

- 復習の右上のかばんアイコン（職場で使えた）を押してから評価すると、状態が「使える」になります
- 受信箱からは毎日「1日の新規カード」の枚数まで、優先度順・古い順で自動的に学習に入ります
- 間隔を変えたいときは 03_設定 の「復習間隔」を書き換えて同期します

## アプリを更新するとき

ファイルを直したら、`sw.js` の `VERSION`（例：`grass-v1.0.1`）を上げてからアップロードしてください。
スマホ側は、次に開いたときに裏で新しい版を取得し、その次に開いたときから新しい版になります。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 入口 |
| `css/app.css` | デザイン（キャンバス「Grass Japanese PWA」の色・文字・寸法。ダークモード対応） |
| `js/app.js` | 7つの画面と操作 |
| `js/srs.js` | 復習のルール、今日のセッションの組み立て |
| `js/sync.js` | シートとの同期 |
| `js/store.js` | スマホ内の保存（IndexedDB） |
| `js/demo.js` | デモ用カード |
| `sw.js` | オフライン対応（Service Worker） |
| `manifest.webmanifest`, `icons/` | インストール用 |

## 安全について

トークンは設定画面で入れたスマホの中にだけ保存されます。スマホをなくしたときは、
スプレッドシートのメニュー「Grass > トークンを再発行」で古いトークンを無効にしてください
（そのあと、Claude のスキルは 10_API設定 から新しいトークンを自動で読みます）。
